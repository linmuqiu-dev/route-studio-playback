# 路线工坊与路线回放器

两款独立的 Windows x64 工具。路线工坊可以手绘、编辑和导出路线。路线回放器可以读取 GPX，通过 MuMu 模拟器回放合成 GPS 轨迹。

## 下载安装

到 [GitHub 发布页](https://github.com/linmuqiu-dev/route-studio-playback/releases/latest) 的 **Assets** 区域下载所需的安装包。

| 需要做什么 | 应下载的文件 |
| --- | --- |
| 在地图上画路线、设置圈数或分段速度、预览并导出 GPX | `RouteStudio-1.3.0-Windows-x64-Setup.exe` |
| 载入 GPX、设置起点，并以选定的匀速在 MuMu 中回放 | `RoutePlayback-1.3.0-Windows-x64-Setup.exe` |

安装后从 Windows 开始菜单打开“路线工坊（发布版）”或“路线回放器（发布版）”。两款软件均已内置 Node.js，可单独安装。回放需要另行安装并启动 MuMu 模拟器。

## 第一次使用

1. 在工坊选择起点，沿地图点击或手绘路线，设置速度，然后点击“导出路线包”。
2. 在回放器选择刚导出的路线。已有 GPX 文件也可以直接导入。
3. 核对模拟器编号，点击“设置起点”，确认模拟器内地图的位置正确后开始回放。需要提前结束时，点“停止”。

工坊保留手绘和固定示例。路线、草稿和回放日志保存在当前用户的 `%LOCALAPPDATA%\RouteTools\Published`。两款软件通过其中的 `exports` 文件夹共享导出结果。底图需要网络，使用空白画布可以离线编辑。
